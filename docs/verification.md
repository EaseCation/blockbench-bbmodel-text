# v0.2.4 建模穿插、贴图归属、格式 UV 与性能

2026-11-15。来源：美术反馈烘焙文字在建模中途“校验分辨率尺寸，不一致就放弃编辑，且不删除已烘焙贴图”。通过 Blockbench 5.2.2 桌面版 + MCP，在真实建模流程中穿插移动、缩放、翻转、旋转、贴图缩放、修改工程 UV 尺寸、复制粘贴、删除和撤销重做复现。

## 修复

- 贴图归属：文字只复用自己生成且独占的贴图，不再改写用户贴图；文字改到新贴图、删除、剪切或贴图被替换后，无人引用的生成贴图在同一 Undo 事务中释放，撤销可恢复。
- 不再因常见建模操作挂起：翻转/90° 旋转改为采纳所在面并保留镜像与面旋转；调整文字贴图尺寸映射为最接近的密度（新增 8×、16×）；只有绘制像素、部分或额外 UV 映射、贴图被替换才挂起，编辑挂起文字时弹窗确认丢弃手工修改。
- 格式 UV：Java 方块、基岩方块按工程 UV 分辨率写 UV；修改 UV 尺寸（调整/保持）都接受；Blockbench 撤销“修改 UV 尺寸”不恢复工程分辨率的原生问题，以及 0.2.3 保存的像素 UV 文件，在恢复时按指纹校正。
- 单贴图格式（基岩实体、旧版实体、模组实体、皮肤）拒绝添加、编辑、重新生成和旧版转换并说明原因；粘贴进来的文字保持原样，不改写模型贴图。
- 性能：原生 Undo 按需参与，普通操作不快照文字；字体资源快照共享字体数据，23 MB 字体下堆内存不再随 Undo 增长；剪贴板像素延迟生成；光栅化使用 CPU 回读画布。

## 验证

- `npm run check`、`npm run format:check` 通过。
- 文字宿主全量 32 项通过。新增：翻转/旋转可编辑、替换或删除贴图的释放与撤销、贴图缩放映射密度及绘制确认、Undo 快照共享字体（0.2.3 上复现失败）、方块格式工程 UV（含撤销 UV 尺寸）、旧版像素 UV 迁移、单贴图格式拦截。移除以“可在基岩实体中创建文字”为前提的旧用例；以及丢弃手工贴图后 Undo 不重复创建用户贴图、超出栅格上限时原生编辑仍可撤销、栅格化后的贴图不被自动释放（第一项在修复前复现失败）。
- 发布前独立审查发现并修复：编辑文字的 Undo 范围在 BEFORE/AFTER 不对称（被替换的用户贴图撤销后重复出现）；派生阶段异常（如 16× 下超出 8192 px）会中断原生 Undo 提交；栅格化后的贴图仍按生成贴图自动释放。运行时 `Blockbench.bbText.version` 同步为 0.2.4。
- 性能（280 元素 / 70 段文字，中位数，含两帧）：选择/移动 13–17 ms，面板按键约 36–44 ms，编辑约 20 ms，全部移动的撤销/重做约 26–30 ms（与无插件持平，原 48 ms），长段落 4×/8×/16× 为 21/27/50 ms（原 60/130/500+ ms）。

已知行为：未安装插件时移动文字，再装插件打开会因指纹包含几何而挂起，可确认丢弃后继续编辑。保存格式向后兼容；运行时版本 0.2.4。

# v0.2.3 普通建模 Undo 隔离

2026-09-24。最小复现：普通模型含 2 个嵌套 Group、3 个 Cube，不创建文字；仅移动其中一个 Cube。旧 0.2.2 文字插件只在 AFTER 加入其余 Cube/纹理，造成撤销误删、重做时丢失原父级。原版和仅 UI Studio 对照通过，仅文字插件和双插件复现。

## 框架调整

- 原生事务的参与者与前后快照集中到 `src/blockbench/native-edits.ts`，carrier 只负责内容派生。
- 不替换宿主的 aspects 数组，不扩大到全项目 Cube/Mesh 或无关纹理；原始宿主范围与文字参与者成对捕获。
- 同一快照流程覆盖取消、第一次粘贴、删除最后一个文字及资源从无到有的恢复；UI 文档继续委托 UI Studio，独立运行没有 UI Studio 依赖。
- 字体查询只读；不会因加载、选择或 Undo 往普通模型写入默认字体。

## 验证

- `npm run check`：类型、8 组脚本测试及生产构建通过。字体资源测试新增查询不写项目的断言。
- 文字宿主全量 24 项：23 项一次通过；新加入的延迟加载用例仅因未设置的 `bb_text` 与原生默认值 `null` 比较不同而失败。统一“无文字”的比较后，两个独立协调层用例复测通过；没有放宽结构、像素或历史范围断言。
- 独立复测显式设置不存在的 `MCUI_DIR`，仅提供 `BLOCKBENCH_HOST_DIR`，确认不需要 UI Studio 构建：普通模型、已有纹理的混合模型、文字原生缩放、复制、最后文字删除、首次粘贴、取消全部通过。
- UI Studio 新增普通建模 8 项：四组安装组合、自由/基岩/Java 方块完整编辑链、Mesh 顶点和取消；完整结构、几何、UV、像素、无插件重开及卸载验证通过。往返夹具修正为在空项目解析文件，角度 -0/0 按 JSON 语义比较。
- UI Studio 相关原有编组、工作区/工具栏恢复及卸载用例 5 项复核通过。两个仓库最终格式与差异检查通过。
- 原有文字能力覆盖两个插件加载顺序、旧文字转换、外部绘画保护、高清贴图、百分比布局、字体剪贴板、缺失 provider、热卸载、IME、双击编辑和资源缓存。
- 默认软件 WebGL 宿主在本机高负载下出现启动/长用例超时；最终使用相同隔离 Blockbench 5.2.1 / Chrome 的 ANGLE Metal 复核。可通过 `BLOCKBENCH_TEST_ANGLE=metal` 复现，默认仍为 SwiftShader。没有修改用户桌面配置。

修复适用于更新后产生的历史，不重写旧版本已经损坏的 Undo 记录。源文件、几何和贴图保存契约不变；运行时版本 0.2.3。
