# v0.2.3 普通建模 Undo 隔离

2026-09-24。最小复现：普通模型含 2 个嵌套 Group、3 个 Cube，不创建文字；仅移动其中一个 Cube。旧 0.2.2 文字插件只在 AFTER 加入其余 Cube/纹理，造成撤销误删、重做时丢失原父级。原版和仅 UI Studio 对照通过，仅文字插件和双插件复现。

## 框架调整

- 原生事务的参与者与前后快照集中到 `src/blockbench/native-edits.ts`，carrier 只负责内容派生。
- 不替换宿主的 aspects 数组，不扩大到全项目 Cube/Mesh 或无关纹理；原始宿主范围与文字参与者成对捕获。
- 同一快照流程覆盖取消、第一次粘贴、删除最后一个文字及资源从无到有的恢复；UI 文档继续委托 UI Studio，独立运行没有 UI Studio 依赖。
- 字体查询只读；不会因加载、选择或 Undo 往普通模型写入默认字体。

## 验证

- `npm run check`：类型、8 组脚本测试及生产构建通过。字体资源测试新增查询不写项目的断言。
- 文字宿主全量 24 项：23 项一次通过；新加入的延迟加载用例仅因未设置的 `bb_text` 与原生默认值 `null` 比较不同而失败。统一“无文字”的比较后，两个独立协调层用例复测通过；没有放宽结构、像素或历史范围断言。
- 独立复测显式设置不存在的 `MCUI_DIR`，仅提供 `BLOCKBENCH_HOST_DIR`，确认不需要 UI Studio 构建：普通模型、已有纹理的混合模型、文字原生缩放、复制、最后文字删除、首次粘贴、取消全部通过。
- UI Studio 新增普通建模 8 项：四组安装组合、自由/基岩/Java 方块完整编辑链、Mesh 顶点和取消；完整结构、几何、UV、像素、无插件重开及卸载验证通过。往返夹具修正为在空项目解析文件，角度 -0/0 按 JSON 语义比较。
- UI Studio 相关原有编组、工作区/工具栏恢复及卸载用例 5 项复核通过。两个仓库最终格式与差异检查通过。
- 原有文字能力覆盖两个插件加载顺序、旧文字转换、外部绘画保护、高清贴图、百分比布局、字体剪贴板、缺失 provider、热卸载、IME、双击编辑和资源缓存。
